# Support

Use GitHub Issues for reproducible bugs and feature proposals. Before filing, run `npm run check`, search existing issues, and reduce the problem to synthetic data.

This community project cannot provide account recovery, platform moderation appeals, guaranteed selector maintenance, or help bypassing platform restrictions. Never share login cookies, QR codes, browser profiles, tokens, or real user media.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
