# Code of Conduct

We want this project to be a respectful, practical, and safe place to collaborate.

Participants must communicate constructively, respect different backgrounds and experience levels, avoid harassment or discriminatory behavior, and never pressure others to expose credentials, personal data, or unauthorized platform access. Responsible automation and respect for platform rules are part of this project's community standard.

Project maintainers may edit or remove abusive content and restrict participation when necessary. Report conduct concerns privately through the repository's security advisory channel when public disclosure would expose personal or sensitive information.
